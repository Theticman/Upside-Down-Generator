# Upside-Down-Generator

This is a generator to automatically create upside down Translation for Minecraft Crowdin.

## Links

- **Generator:** [theticman.github.io/Upside-Down-Generator](https://theticman.github.io/Upside-Down-Generator/) — paste text in and get the flipped, reversed, parameter-reindexed output.
- **Rulebook:** [RULEBOOK.md](RULEBOOK.md) — the conventions for translating Minecraft into the Upside Down English locale.
